The problem

Philadelphia publishes rental license data across four public surfaces. Every one shows only a license’s current state. When a license expires and is later renewed, the lapsed period is overwritten and disappears — permanently, from every public system.

A real case — license 602204, 315-23 N 12th St, 163 units.
Expired Feb 28, 2026. Renewed Aug 2, 2026. That is roughly 155 days unlicensed.
Today every public system reads Active, expiration Feb 28, 2027, inactive date blank. Property History displays “Date issued: Aug 12, 2013” beside “Active” — as though the license had run uninterrupted for thirteen years. The gap is invisible everywhere.

What this does

Once a day this project pulls the City’s public Carto data, compares it against yesterday, and appends only what changed to a permanent log. Each day is committed to Git, so every entry is timestamped and tamper-evident. Going forward it captures every expiration, every renewal, and every status change — with the date it happened.

How to use it

Download the log

curl -O https://thumpersecure.github.io/phl-rental-license-log/changes.ndjson

One JSON object per line (NDJSON).

Look up a single license

grep '"licensenum":"602204"' changes.ndjson | jq .

Every license that expired

jq -c 'select(.diff.licensestatus.to == "Expired")' changes.ndjson

Every lapse that was later closed (the lapse detector)

jq -c 'select(.diff.licensestatus.from == "Expired" and
              .diff.licensestatus.to   == "Active")' changes.ndjson

Check the latest run

curl -s https://thumpersecure.github.io/phl-rental-license-log/latest.json | jq .

Record shapes

 "diff":{"licensestatus":{"from":"Expired","to":"Active"}}, "new":{…}}

{"ts":"…","licensenum":"000001","change":"initial","new":{…}}
{"ts":"…","licensenum":"…","change":"left_set","last":{…}}

Tracked fields: licensestatus, expirationdate, mostrecentissuedate (renewal), inactivedate, plus address, OPA account and ZIP.

Honest limits. This captures history only going forward from 2026-08-21. It cannot recover license 602204’s Feb–Aug 2026 lapse — that is already gone from every public system. The next cycle (602204 expires again Feb 28, 2027) is the first this log will document with hard evidence.
