What the City keeps, and what it discards

Philadelphia publishes rental license data across four public surfaces. Every one shows only a license’s current state. When a license expires and is later renewed, the lapsed period is overwritten — no public system can tell you what a license’s status was on a given past date.

Violations are different. When L&I cites a property for operating without a valid rental license, that record is permanent. It carries its own dates, case number, resolution and public notice document — and a later renewal does not erase it. That enforcement history reaches back to 2010.

What each source answers
Was this license expired on a given past date?Not available — overwritten
When was it last renewed?Available — mostrecentissuedate
Was the property cited for operating unlicensed, and when?Available & permanent — since 2010
The gap that remains. Not every lapse produces a violation. A license that expires and is renewed before an inspector visits leaves no enforcement record — and no status history either. Those lapses are invisible in every public system. That is what the daily license log is for: it records the change as it happens, so a silent lapse is still documented.

What this does

Once a day this project pulls the City’s public Carto data and appends only what changed to permanent logs. Each day is committed to Git, so every entry is timestamped and tamper-evident.

  • License log — 96,879 Active/Expired rental licenses, diffed daily. Captures expirations, renewals and status flips as they happen, from 2026-08-21 forward.
  • Violations archive — 25,946 rental-license violations under Phila. Code § 9-3902, 2010 to present. Already-existing history, kept current daily.

How to use it

Download the log

curl -O https://thumpersecure.github.io/phl-rental-license-log/changes.ndjson

One JSON object per line (NDJSON).

Look up a single license

grep '"licensenum":"602204"' changes.ndjson | jq .

Every license that expired

jq -c 'select(.diff.licensestatus.to == "Expired")' changes.ndjson

Every lapse that was later closed (the lapse detector)

jq -c 'select(.diff.licensestatus.from == "Expired" and
              .diff.licensestatus.to   == "Active")' changes.ndjson

Find every property cited for operating unlicensed

curl -O https://thumpersecure.github.io/phl-rental-license-log/violations_changes.ndjson

jq -c 'select(.new.violationcode | startswith("9-3902"))
       | {case:.new.casenumber, addr:.new.address,
          issued:.new.violationdate, status:.new.violationstatus,
          resolved:.new.violationresolutiondate}' violations_changes.ndjson

Violations for one address

grep '"address":"315-23 N 12TH ST"' violations_changes.ndjson | jq .

Each record includes publicnov — a direct link to the City’s official Notice of Violation PDF.

Check the latest run

curl -s https://thumpersecure.github.io/phl-rental-license-log/latest.json | jq .

License fields tracked: licensestatus, expirationdate, mostrecentissuedate (renewal), inactivedate, plus address, OPA account and ZIP.
Violation fields tracked: violationcode, violationcodetitle, violationstatus, violationdate, violationresolutiondate, casestatus, underappeal, publicnov.

Scope. The violations archive is complete history — every § 9-3902 citation the City has issued since 2010. The license log is forward-capturing: it records status changes from 2026-08-21 onward and cannot reconstruct a license’s status before that date.
